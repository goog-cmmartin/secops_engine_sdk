# Computation

```sql
rule feed_timestamp_skew {
  meta:
    description = "Audit ingestion pipeline clock skew and transport delay across all feeds"
    severity = "INFORMATIONAL"
    author = "SecOps Engine SDK"
  events:
    $e.metadata.event_timestamp.seconds > 0
  match:
    $e.metadata.log_type over 1h
  outcome:
    $event_count = count($e.metadata.id)
    $avg_latency_minutes = avg(($e.metadata.collected_timestamp.seconds - $e.metadata.event_timestamp.seconds) / 60)
    $clock_skew_count = count(if($e.metadata.collected_timestamp.seconds < $e.metadata.event_timestamp.seconds, 1, 0))
  condition:
    $e
}
```

This sanctioned computation calculates three invariant health metrics:
1. **Total Ingested Volume:** Total count of UDM events partitioned by `metadata.log_type`.
2. **Mean Transport Latency:** Average minutes between source emission (`event_timestamp`) and ingestion ingestion receipt (`collected_timestamp`).
3. **Negative Delta (Clock Skew):** Events where `collected_timestamp < event_timestamp`, indicating skewed endpoint clocks or misconfigured parser timezone offsets.
