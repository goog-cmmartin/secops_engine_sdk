# Personas

Operational agent roles, mandates, authority tiers, and assigned procedures within the SecOps Engine SDK.

## Personas Directory

- [Detection Engineer](detection_engineer.md): Owns YARA-L 2 rule health, false positive suppression, detection lifecycle, and retrohunt audits.
- [Ingestion Specialist](ingestion_specialist.md): Owns feed health, BindPlane agent fleet rollout, log parser errors, and timestamp integrity.
- [Platform Engineer](platform_engineer.md): Owns tenant configuration posture, workforce identity federation, UDM performance, and GCP infrastructure.
- [SOC Analyst](soc_analyst.md): Owns incident triage, SOAR case assignment, playbook health, and alert response workflows.
